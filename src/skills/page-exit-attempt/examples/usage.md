# Using Page Exit Attempt

### How to Test
Execute these actions after injecting the script:

1. **Click a Link**: Click any link that leads to a different URL (or even the same one if it reloads).
2. **Back/Forward**: Use the browser's navigation buttons.
3. **SPA Navigation**: If the app uses a router (like React Router), navigate between pages.
4. **Submit a Form**: Click a submit button.

Check the console to see the detected interaction type and destination.
